# ICM Landing Page

Landing page da Igreja Crista Mundial, criada com Next.js e exportada como site estatico para GitHub Pages.

## Como rodar localmente

```bash
pnpm install
pnpm dev
```

## Validacao

```bash
pnpm lint
pnpm build
```

## Deploy

O deploy para GitHub Pages acontece automaticamente pelo workflow em `.github/workflows/pages.yml` sempre que houver push na branch `main`.

URL esperada:

```text
https://jovemegidio.github.io/ICM-LandingPage/
```
